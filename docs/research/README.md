# Competitor Research — Elveriq source-of-truth files

Research baseline **2026-11-12**. This directory is carried forward inside the Elveriq source tree to make the long-term plan recoverable from Git without depending on chat memory.

- `Elveriq_Enterprise_WMS_Research_2026.pdf`: printable comprehensive competitor report.
- `Elveriq_Enterprise_WMS_Research_2026.docx`: editable source document.
- `Elveriq_Enterprise_WMS_Research_2026.md`: Git-diffable research paper.
- `Elveriq_Competitor_Feature_Register_2026.csv`: 300 stable EV-NNN feature requirements and acceptance criteria.
- `Elveriq_Research_Sources_2026.csv`: official vendor-source register and URLs.

The paper is a research baseline, **not a claim that all listed features are shipped** and not a substitute for checking current vendor editions or customer needs. Actual delivered work and release gates are documented in `../ELVERIQ_MASTER_BUILD_PLAN.md` and `../WAREHOUSE_EXECUTION.md`. Preserve the EV identifiers and link every implementation issue or acceptance test to its row.
